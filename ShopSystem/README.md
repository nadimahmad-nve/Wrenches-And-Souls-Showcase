# Wrenches & Souls - Shop Architecture

These are the scripts that manage the shop system. 

## Includes:
* **ShopPopulator.luau** Populates the shop with UI assets and links buttons to different actions. All potential purchases are routed to the server to verify. 
* **CrateOpener.luau** Handles the crate opening gacha system, and sends the result to the client, where the visuals are rendered.
