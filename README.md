# Wrenches & Souls - Scripts Showcase
This repository is a showcase for some of the key systems I've coded for my asymmetrical game, *Wrenches & Souls*.

## Includes:
* **Generator Repair System** The robust scripts allowing players to successfully fix repairable objects.
* **Round Loop** Some scripts displaying how the game cleanly transitions into different states, such as from the intermission into an actual round.
* **Inventory + Shop System** The Shop demonstrates the economy of the game, allowing players to open crates for rewards. The Inventory System demonstrates the clean architecture behind saving and loading the players' items, enabling them to equip/unequip as they desire.   
* **State Manager** The State Manager defines how players can seamlessly move between different states during a game. States are given a priority and this is adhered to, dealing with overlapping states smoothly.
